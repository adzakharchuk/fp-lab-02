# Завдання та критерії оцінювання — варіант 5

**Тема:** Спортивний рейтинг.

**Структура:** спортсмени `id`, `name`, `category`, `results`.

**Конвеєр:** обчислити кращий/середній результат; застосувати бонус вибраної категорії; відфільтрувати допущених спортсменів; сформувати рейтинг Top-N.

**Reduce-агрегація:** `count`, `sum_points`, `avg_points`.

## Обов'язкові критерії
1. Типізований запис через `TypedDict`.
2. Не менше чотирьох чистих трансформацій без зміни вхідних записів.
3. Використання `map`/`filter` або генераторних еквівалентів.
4. Реалізація `compose` або `pipe` та використання для побудови конвеєра.
5. Не менше двох доречних `lambda`.
6. Сортування за двома ключами та Top-N.
7. `reduce`-агрегація з трьома показниками.
8. `pytest`-тести для Top-N, відсутності мутацій, агрегації та композиції.
9. Відокремлення CLI/I/O від чистих функцій.
10. README та проходження Black, Ruff, mypy.
